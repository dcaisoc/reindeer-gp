# Security

Please report security problems privately by email to **dcaisoc@outlook.com**, not as a public issue. Include what you found and how to reproduce it. We aim to reply within 3 days.

In scope: anything that lets someone change a leaderboard result without a genuine run, read or change another player's data, run code on our servers, or take the site down.

The game runs entirely in your browser in M1; there is no server or account data yet.
